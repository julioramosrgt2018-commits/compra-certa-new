Compra Certa

Aplicação Web Progressiva (PWA) desenvolvida para otimizar as compras de supermercado, com controlo de carrinhos, saldos de cartões de benefício, leitura de códigos de barras, controlo inteligente de datas de validade com alertas visuais automáticos, fotografia de cupom fiscal e histórico de preços.

Funcionalidades
• Registo de Compras e Código de Barras: Leitura por câmara ao vivo.
• Validade Manual Direta: Registo prático de vencimentos no carrinho.
• Alertas Visuais de Validade: Identificação imediata na aba Validade para produtos vencidos, a vencer hoje ou próximos do prazo.
• Lista Inteligente / Base de Dados: Reutilização de itens comprados anteriormente com validação rápida de código de barras.
• Conferência de Cupom Fiscal: Comparação visual lateral com o carrinho.
• Comparador de Preços: Análise de valores entre supermercados com base no histórico.
• Gestão de Benefícios: Controlo de saldos para cartões de Alimentação e Refeição.
